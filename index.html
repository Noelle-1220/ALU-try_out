Find Your BSE Specialisation Path

Not sure which Bachelor of Software Engineering track fits you best? Answer a short interactive quiz and discover whether Low-Level Programming, AR/VR, Full-Stack Web Development, or Machine Learning matches your interests and strengths.

The Four Specialisation Tracks

Low-Level Programming

+

This track focuses on how computers work close to the hardware level. You will study memory management, operating systems, and languages like C and Assembly. It suits students who enjoy solving puzzles about performance and efficiency.

AR/VR

+

Augmented Reality and Virtual Reality combine 3D graphics, hardware sensors, and creative design to build immersive experiences. This track suits students who enjoy game engines, spatial design, and interactive storytelling.

Full-Stack Web Development

+

Full-stack development covers both the front end (what users see) and the back end (servers, databases, APIs) of web applications. This track suits students who like building complete products people can use directly in a browser.

Machine Learning

+

Machine Learning focuses on training computer models to recognise patterns in data and make predictions. This track suits students who enjoy mathematics, statistics, and experimenting with data-driven problem solving.
